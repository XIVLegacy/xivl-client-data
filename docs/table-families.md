# Table Families

Use this table to choose the CSV families relevant to a research question.

| Family | Example Tables | Useful For |
|---|---|---|
| Items | `itemData.csv`, `xtx_itemName.csv`, `weapon.csv`, `armor.csv`, `accessory.csv`, `equipment.csv` | Item catalog, equipment, names, shop and inventory lookup. |
| Commands and status | `command.csv`, `xtx_command.csv`, class command sheets, `status.csv`, `xtx_status.csv` | Actions, traits, status effects, combat UI, command text. |
| Shops and market | `shopBase.csv`, `shopItem.csv`, `marketItem.csv`, `blackMarket.csv` | Shop catalogs, market categories, retainer/ward research. |
| Actors and events | `actorclass.csv`, `actorclass_graphic.csv`, `actorclass_mapObj.csv`, `populace*.csv`, object/gimmick sheets | Actor presentation, event surfaces, NPC families. |
| Quests and leves | `quest.csv`, `quest_reward.csv`, `guildleve.csv`, `guildlevePack.csv`, `guildleve_UI.csv` | Quest/leves static presentation and rewards. |
| Maps and travel | `_zoneParam.csv`, `regionParam.csv`, `aetheryte.csv`, `2Dmap_*.csv`, `mapNavi_data.csv` | Zone ids, aetherytes, maps, navigation, transfer research. |
| Text | `xtx_*.csv`, `worldMaster.csv`, `ordinaryRetainer.csv` | Localized text, control-code markers, UI strings, system messages. |
